------------------------------------------------------------
ISLAMIC COMPLIANCE ENGINE
------------------------------------------------------------

Every contract is automatically analysed.

Checks include:
  • Riba detection
  • Interest wording
  • Prohibited clauses
  • Missing Islamic considerations
  • Ambiguous wording

If prohibited wording is detected:
  Large warning displayed.
  Example: "This contract appears to contain Riba."

  AI then:
  • Highlights the clause
  • Explains why it is prohibited
  • Suggests halal wording

Wafa never generates interest-bearing contracts.

------------------------------------------------------------
RAHN (COLLATERAL)
------------------------------------------------------------

If secured, AI asks: "What is being used as collateral?"

Quick options:
  • Gold
  • Silver
  • Jewellery
  • Vehicle
  • Property
  • Cash
  • Electronics
  • Watches
  • Business Equipment
  • Other

Collect:
  • Description
  • Quantity
  • Condition
  • Photos
  • Ownership confirmation
  • Serial numbers
  • Supporting documents

Collateral Value — Record:
  • Estimated value on contract date
  • Date recorded
  • Agreed value
  • Future market estimate

Timeline records:
  • Collateral added
  • Collateral released
  • Collateral returned
  • Collateral disputed

Future: AI may estimate live market value where reliable
data exists.

------------------------------------------------------------
MULTI-LANGUAGE CONTRACTS
------------------------------------------------------------

During contract creation AI asks:
  "Would you like this contract available in multiple
  languages?"

If Yes — select additional languages:
  Arabic / Urdu / Turkish / French / Bengali /
  Malay / Indonesian / Spanish / Other

The contract stores:
  • One primary language
  • One or more translated versions

Users can instantly switch between languages.
The governing language of the contract can be identified.
Future: AI compares translations for consistency.

------------------------------------------------------------
TIMELINE
------------------------------------------------------------

Permanent audit trail. Nothing is deleted.
Everything is timestamped.

Events:
  Contract Created / Edited / Viewed / Shared / Signed /
  Witness Signed / Reminder Sent / Payment Recorded /
  Partial Payment / Extension / Collateral Added /
  Collateral Returned / Completed / Dispute Opened

------------------------------------------------------------
SMART REMINDERS
------------------------------------------------------------

Generated automatically from contract dates.

Reminder types:

------------------------------------------------------------
PRIVATE ISLAMIC FINANCE ASSISTANT
------------------------------------------------------------

Each contract includes a private financial assistant
for each party. Answers remain completely private — the
other party never sees responses.

Optional questions help explain:
  • Cash flow impact
  • Financial planning
  • Repayment ability
  • Islamic financial considerations

AI provides educational guidance only.

------------------------------------------------------------
ZAKAT ASSISTANT
------------------------------------------------------------

Educational guidance relating to:
  • Money lent
  • Money borrowed
  • Outstanding repayments
  • Potential zakat implications

Users are reminded that personal zakat rulings should
always be confirmed with a qualified scholar.
